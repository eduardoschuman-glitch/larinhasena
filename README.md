# Lara Sena Beauty

Landing page one-page da **Lara Sena Beauty** — estética do olhar (sobrancelhas, lash lifting) em Porto Alegre/RS.

Site estático (HTML, CSS e JavaScript puro), sem dependências de build.

## Estrutura

```
index.html          Página principal
styles/style.css     Estilos
scripts/script.js    Slideshows, carrosséis, modal e dados dos serviços
assets/              Imagens, logos, borboleta e ícone do WhatsApp
```

## Como rodar

Abra `index.html` no navegador, ou publique a pasta em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

### GitHub Pages
1. Suba estes arquivos no repositório.
2. Settings → Pages → Branch: `main` / pasta `/root`.
3. O site fica disponível em `https://<usuario>.github.io/larasenabeauty/`.
